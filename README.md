# PrintPrep Local 無料オープンテスト

PNGの寸法、数量、小さな点や透明な輪郭を、このPC内で確認するWindows用ソフトです。元画像と修正後を並べて見て、必要な変更だけを選びます。

初回テストは無料です。Windows 11 x64向け、未署名の試験版です。まず同梱の架空の練習画像で、起動→比較→保存の取消→保存し直し→再開を試してください。別PCでの動作確認も、このテストの目的に含めています。
